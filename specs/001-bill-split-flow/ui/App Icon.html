Pure SVG, no rasters — every icon is exported as a single 1024×1024 vector you can hand to Xcode (App Icon set) and Android Studio (Image Asset → Adaptive Icon). The 22.37% rounded mask shown for iOS is what the OS will apply automatically; Android's adaptive icon will use a 108×108 dp foreground inside the 72-dp safe zone, so for D & A in particular, keep the safe zone in mind during the export.
